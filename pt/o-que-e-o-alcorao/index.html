O que é o Alcorão?

O Alcorão é a palavra de Deus revelada ao Profeta Muhammad ﷺ ao longo de 23 anos, preservada em árabe até hoje. É um guia para toda a humanidade.

«Esse é o Livro. Nele, não há dúvida alguma. É orientação para os piedosos»

Alcorão 2:2

Os versículos são citados palavra por palavra de uma tradução oficial do Alcorão: Dr. Helmi Nasr — QuranEnc.com ↗
